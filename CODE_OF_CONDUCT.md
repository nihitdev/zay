# Code of Conduct

The zay project welcomes respectful participation from people with different
backgrounds and levels of experience. Contributors are expected to:

- Be considerate, patient, and constructive.
- Discuss technical disagreements respectfully and focus on the work.
- Accept feedback and corrections in good faith.
- Avoid harassment, insults, discrimination, intimidation, and unwelcome
  attention.
- Respect the project's safety boundaries, including its treatment of AUR build
  files as untrusted code.

These expectations apply in project issues, pull requests, reviews, and other
spaces where someone represents the project.

Project maintainers may edit or remove contributions that violate this code and
may restrict participation when necessary. To report a conduct concern, contact
the maintainers privately through the GitHub repository. Reports will be handled
with discretion.
